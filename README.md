# ReelNote

ReelNote is a personal movie journal designed for movie lovers who want a simple way to document their movie-watching experiences. This application allows users to track movies they have watched, rate them on a scale of 1-10, and write personal reviews to capture their thoughts and impressions.

Whether it's a movie watched yesterday or years ago, ReelNote provides an organized space for users to revisit their viewing history and reflect on their experiences. ReelNote makes it easy for movie lovers to remember the movies they've watched and how they felt about them. 

# Installation

**1. Clone the Repository**

```bash
git clone https://github.com/joe-nguyenn/ReelNote.git
```

**2. Navigate to the Project Directory**

```bash
cd ReelNote
```

**3. Install Django**

```bash
python -m pip install django
```

**4. Set Up the Database**

```bash
python manage.py migrate
```

# Getting Started

To start ReelNote, open a terminal (make sure you are still in the project directory) and simply run:

```bash
python manage.py runserver
```

Once the server starts, open a web browser and navigate to:

http://127.0.0.1:8000/

To stop the server, press `Ctrl + C` in the terminal.
